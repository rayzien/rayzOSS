# Contributing to rayzOSS

Thank you for your interest in contributing to **rayzOSS**!

This project was created and is actively maintained by:
- **[rayzien](https://github.com/rayzien)**
- **[pheonix14](https://github.com/pheonix14)**

---

### How to Help
1. **Star and Fork:** Please star the repo on GitHub!
2. **Report Issues:** Found a bug or have an idea? Open an issue.
3. **Submit Pull Requests:** Bug fixes, performance improvements, and new sharding algorithms are welcome.

### Development & Testing
Run the built-in test suite before submitting any PR:
```bash
python3 -m app.tests.test_suite
# or using the CLI:
oss test
```

### Code Style
- Use standard library modules whenever possible to keep rayzOSS lightweight with zero external dependencies.
- Ensure compression retains 100% bit-for-bit lossless quality.
